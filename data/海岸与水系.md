# 海岸、水系与海域纹理

海岸、水系和海域均取自 Natural Earth 1∶1000 万的公共领域矢量数据。陆地以 `Land` 5.1.1 为准，内陆水域使用 `Lakes + Reservoirs` 5.0.0 与 `Rivers + lake centerlines` 5.0.0。河流线宽按数据的制图等级赋值，湖面使用原始水面范围。海域深浅使用 `Bathymetry` 4.1.0 中由 SRTM Plus 派生的等深面平滑着色，最深色对应 5,000 米及更深水域。[陆地](https://www.naturalearthdata.com/downloads/10m-physical-vectors/10m-land/) · [湖泊和水库](https://www.naturalearthdata.com/downloads/10m-physical-vectors/10m-lakes/) · [河流](https://www.naturalearthdata.com/downloads/10m-physical-vectors/10m-rivers-lake-centerlines/) · [海底地形](https://www.naturalearthdata.com/downloads/10m-physical-vectors/10m-bathymetry/) · [使用条款](https://www.naturalearthdata.com/about/terms-of-use/)

## 构建中间纹理

香港迪士尼所在的竹篙湾有一处填海地。全国底图的海陆掩膜每格约 1.5 公里，在城堡位置将海陆混合格判作了海面。打包纹理时使用现状海堤线补绘填海区，点选和地标落地共用这段海岸多边形。补区南、东边缘取自 OpenStreetMap，西北侧在已有陆地内闭合。[补充范围与来源](香港竹篙湾海岸.geojson) · [竹篙湾海堤](https://www.openstreetmap.org/way/1376709729) · [香港土木工程拓展署填海说明](https://www.cedd.gov.hk/eng/our-major-services/fill-management/marine/marine-fill/index.html) · [© OpenStreetMap 贡献者](https://www.openstreetmap.org/copyright)

鼓浪屿八卦楼、天涯海角题刻巨石及青岛栈桥岸端同样采用实测岸线校正海陆掩膜。鼓浪屿由两段岸线闭合成岛，后两处在既有陆地内闭合。来源、节点范围和坐标保存在各自的 GeoJSON 中。[鼓浪屿](福建鼓浪屿海岸.geojson) · [天涯海角](海南天涯海角海岸.geojson) · [青岛栈桥](山东青岛栈桥海岸.geojson) · [© OpenStreetMap 贡献者](https://www.openstreetmap.org/copyright)

在项目根目录运行，建议使用 Python 3.11 或更新版本。

```sh
python3 -m venv .venv
.venv/bin/python -m pip install -r scripts/terrain-requirements.txt
.venv/bin/python scripts/build_hydrography.py \
  --cache /tmp/china-atlas-texture/sources \
  --output /tmp/china-atlas-texture/hydrography.webp
```

原始数据存入 `--cache` 目录，生成脚本读取 `app/public/data/terrain.json` 的投影和范围。图像自北向南排列，首末像素中心与三维高程网格外端顶点对齐。海岸与水系按三倍分辨率栅格化后面积平均。输出无损 WebP 的红、绿、蓝通道分别表示陆地覆盖率、内陆水域覆盖率、海域深浅。伴随的 `hydrography.json` 记录数据来源、文件 SHA-256 和通道含义。
