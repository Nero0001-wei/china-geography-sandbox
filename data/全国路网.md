# 全国道路概览

沙盘的离线路网取自 Natural Earth 1∶1000 万 Roads 5.0.0，适合在全国和区域视图辨认公路走廊。源数据为公共领域的地理概览，线路经过制图综合，中国范围内的记录缺少路名、路号和车道信息。出行方案继续使用规划服务返回的分段轨迹。[Natural Earth 数据说明](https://www.naturalearthdata.com/downloads/10m-cultural-vectors/roads/) · [5.0.0 原始文件](https://naturalearth.s3.amazonaws.com/5.0.0/10m_cultural/ne_10m_roads.zip) · [使用条款](https://www.naturalearthdata.com/about/terms-of-use/)

## 范围与分级

制作时采用[项目底图的 139 个面域](../app/public/data/china-boundaries.json)裁剪道路，主图包含大陆、海南岛和台湾岛等有源道路的陆地。路段跨越边界时在交点拆开。坐标保持 WGS84，经度在前、纬度在后，和沙盘现有地形投影共用同一定位基准。

| 显示层级 | 源数据条件 | 线段 | 顶点 |
| --- | --- | ---: | ---: |
| 高速 `expressway` | `expressway = 1` | 2,712 | 11,401 |
| 干线 `arterial` | 其余 `Major Highway`，以及制图等级 `scalerank ≤ 5` 的道路 | 2,296 | 12,186 |
| 一般道路 `secondary` | 其余可辨认的公路，包括仅有制图等级的记录 | 7,138 | 43,563 |

脚本筛选道路要素，排除小径与渡运。原始的 `Unknown` 表示未标明公路类别，按源制图等级显示。干线和一般道路的分组用于控制沙盘显示密度。折线保留共用节点和原有分段端点，区间内以 0.004° 容差简化，再裁去越出边界的部分，经纬度保留四位小数。

## 重建

在项目根目录安装既有的边界处理依赖，然后运行预处理。

```sh
python3 -m venv .venv
.venv/bin/pip install -r scripts/boundary-requirements.txt
.venv/bin/python scripts/build_road_network.py
```

脚本默认下载固定版本的源文件，核对 SHA-256 后写入 [overview.json](../app/public/data/roads/overview.json)。有本地源文件时，加 `--archive /path/to/ne_10m_roads.zip` 即可离线重建。[预处理脚本](../scripts/build_road_network.py)

## 数据核对

输出共 12,146 段、67,150 个顶点，文件 1,274,623 字节。同一源文件重复生成的结果逐字节一致。按共用坐标建立无向图抽查，北京、南京、上海、杭州、合肥、广州、拉萨与乌鲁木齐市中心附近的道路节点都位于同一连通分量。海南岛与台湾岛均有三个层级的道路，跨海行程的显示几何由相应的交通方案提供。

## 近景道路

放大到区域和城市尺度时，沙盘按视野请求 OpenFreeMap 的公开矢量瓦片，从交通图层解码公路折线和道路标注。编号来自原始数据。按瓦片自身的 Web Mercator 坐标反算经纬度后，折线再投影到沙盘并沿地形网格贴合。近景道路随视野加载，边境附近可能同时看到相邻地区的道路。[OpenFreeMap](https://openfreemap.org/) · [© OpenMapTiles](https://openmaptiles.org/) · [© OpenStreetMap 贡献者](https://www.openstreetmap.org/copyright)

底图和高德行程使用独立的数据源，更新时间、道路几何和简化尺度可能不同。近景瓦片暂时不可用时，地图继续显示本地概览。

桌面与手机均验证了图层切换、南京近景街道及网络失败时的本地概览。南京近景瓦片实测包含 G42、G25、内环西线、龙蟠路等编号及路名。[南京路网预览](../output/南京路网近景.png)
