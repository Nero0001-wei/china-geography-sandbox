# 全国地形数据

地形使用 USGS 与 NGA 的 GMTED2010 30 角秒平均高程，水平坐标为 WGS84，海拔基准为 EGM96。采用 USGS 提供的全球 ArcGrid 原档。脚本也可拼接同产品的 30 角秒平均高程 GeoTIFF 分幅。海陆位置由 Natural Earth 1:10m Land 5.1.1 的陆地范围确定，陆地低于海平面的点保留负值。[USGS 数据下载页](https://topotools.cr.usgs.gov/gmted_viewer/gmted2010_global_grids.php) · [GMTED2010 技术报告](https://pubs.usgs.gov/publication/ofr20111073) · [Natural Earth Land](https://www.naturalearthdata.com/downloads/10m-physical-vectors/10m-land/)

## 复现

在项目根目录执行，建议使用 Python 3.12。原档约 277 MB，生成的网页数据随项目保存。

```sh
python3 -m venv .venv
.venv/bin/pip install -r scripts/terrain-requirements.txt
mkdir -p /tmp/china-relief-input
curl -fL 'https://edcintl.cr.usgs.gov/downloads/sciweb1/shared/topo/downloads/GMTED/Grid_ZipFiles/mn30_grd.zip' -o /tmp/china-relief-input/gmted.zip
curl -fL 'https://naturalearth.s3.amazonaws.com/10m_physical/ne_10m_land.zip' -o /tmp/china-relief-input/land.zip
unzip -o /tmp/china-relief-input/gmted.zip -d /tmp/china-relief-input/gmted
unzip -o /tmp/china-relief-input/land.zip -d /tmp/china-relief-input/land
.venv/bin/python scripts/build_terrain.py --dem /tmp/china-relief-input/gmted/mn30_grd --land /tmp/china-relief-input/land/ne_10m_land.shp
```

Rasterio 调用 GDAL，将高程按面积加权平均重采样到 Albers 等积圆锥投影网格。中央经线 105°E，标准纬线 25°N、47°N。网格为 544 × 416 个顶点，横向间距约 16.4 km，纵向间距约 17.1 km。沿原网格向东西各延伸 80 格、南北各延伸 64 格后，覆盖范围约为 8,932 × 7,085 km。网页的垂直夸张只改变渲染高度。[GDAL 重采样](https://gdal.org/en/stable/programs/gdalwarp.html) · [PROJ Albers 投影](https://proj.org/en/stable/operations/projections/aea.html)

## 网页数据

| 文件 | 内容 |
| --- | --- |
| `terrain.json` | 投影、顶点中心范围、横纵单位、缩放系数及数据来源 |
| `elevation.i16` | 小端有符号 16 位高程，单位为米，缺失值 `-32768` |
| `land.u8` | 无符号 8 位海陆掩膜，`0` 为海域，`1` 为陆地 |
| `profile-32n.json` | 沿 32°N 每 0.1° 抽样的源像元高程与三角网插值，附分段均值和逐点平均绝对差 |

两个栅格均从最北一行开始，每行由西向东。海陆掩膜按顶点中心栅格化，部分小岛和曲折岸线需要用矢量层呈现。

## 陆地配色与晕渲

全国地表底图为 8710 × 6910 像素，使用与高程网格相同的投影和范围。NASA Blue Marble Next Generation 2004 年 8 月的月度合成影像提供约 500 米分辨率的地表底色。华东平原的草绿、橄榄绿和浅黄绿由影像中红、绿波段的相对强度和地表亮度连续映射而来。山地按坡面朝向接受西北光照，同时计算窄山脊和宽山坡的明暗。全国图使用 GMTED2010 的 30 角秒平均高程，境内近景使用同产品的 7.5 角秒平均高程。[NASA Blue Marble 影像](https://science.nasa.gov/earth/earth-observatory/blue-marble-next-generation/base-map/) · [USGS GMTED2010 技术报告](https://pubs.usgs.gov/publication/ofr20111073)

地表分类取自 ESA WorldCover 2021 v200。构建时读取与项目边界相交的 152 个 GeoTIFF 分幅的 16 倍降采样层。该层每个方向的角间距为 4.8 角秒，在江苏约为东西 125 米、南北 148 米。每个输出像元按这些采样里各类别所占面积微调配色，例如加深林地、调暖建成区、补绘浅蓝色水面。主要河湖和海岸仍使用 Natural Earth 矢量。[WorldCover 数据集](https://doi.org/10.5281/zenodo.7254221) · [海岸与水系](海岸与水系.md)

从 NASA 页面「August」的原始真彩部分下载北半球 C1、D1 两张 JPEG 后，在项目根目录生成分类缓存和全国地表纹理。WorldCover 分幅与索引保存在构建目录，重新运行时可复用已有分幅。

```sh
.venv/bin/python scripts/prepare_worldcover.py \
  --output /tmp/china-relief-input/cover.vrt

.venv/bin/python scripts/build_relief_texture.py \
  --dem /tmp/china-relief-input/gmted/mn30_grd \
  --imagery /tmp/china-relief-input/world.200408.3x21600x21600.C1.jpg /tmp/china-relief-input/world.200408.3x21600x21600.D1.jpg \
  --land /tmp/china-relief-input/land/ne_10m_land.shp \
  --cover /tmp/china-relief-input/cover.vrt \
  --output /tmp/china-atlas-texture/relief-color.webp
```
