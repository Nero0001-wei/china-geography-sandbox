# 行政边界与南海诸岛附图

- 全国轮廓、省级界线与南海断续线取自阿里云 DataV.GeoAtlas。其文档将数据用途限定为学习交流，底层来源为高德开放平台。全国地形原型按此用途在本地使用。[GeoAtlas 数据说明](https://help.aliyun.com/en/datav/datav-7-0/user-guide/datav-geoatlas-widgets/)
- 物理海陆及附图海岸线使用 Natural Earth 1∶1000 万 `Land` 5.1.1 矢量，属于公共领域。物理海陆掩膜由地形数据工具单独栅格化。[Natural Earth Land](https://www.naturalearthdata.com/downloads/10m-physical-vectors/10m-land/) · [使用条款](https://www.naturalearthdata.com/about/terms-of-use/)
- 全国主图含大陆、海南岛、台湾岛及沿岸岛屿，钓鱼岛、赤尾屿包含在小岛图层。南海诸岛附图包括四群岛、黄岩岛和曾母暗沙，保留海岸、岛礁及断续线的位置关系。原型对照《公开地图内容表示规范》检查上述要素覆盖，边界线的官方逐段校核与公开使用许可待完成。[公开地图内容表示规范](https://ghzyj.gz.gov.cn/zwgk/newzcfg/ywly/content/mpost_9466245.html) · [标准地图服务系统](https://bzdt.tianditu.gov.cn/)

## 生成

在项目根目录使用 Python 3.11 或更新版本。

```sh
python3 -m venv .venv
.venv/bin/python -m pip install -r scripts/boundary-requirements.txt
.venv/bin/python scripts/build_boundaries.py
```

脚本按全国显示比例简化原始边界，从相邻行政区多边形的共享边生成省际线。高德来源几何经 GCJ-02 近似反算后，和 Natural Earth 几何均以经度、纬度顺序输出，供沙盘投影模块调用。文件 `app/public/data/china-boundaries.json` 记录输入链接及 SHA-256；`app/public/data/south-china-sea.json` 提供附图的海岸、岛礁、断续线及地名。可用 `--outline`、`--provinces` 和 `--land` 传入已下载的原始文件。

## 地图搜索中的省市

离线搜索索引 `app/shared/map-places.json` 沿用 GeoAtlas 全国和各省 `*_full.json` 中的行政区名称及 `center` 坐标，经 GCJ-02 近似反算后用于沙盘定位。省级行政区定位到数据记录的行政中心，直辖市各保留一项。城市索引收录源数据提供的地市级条目，定位范围与全国主图一致。源数据的台湾条目没有下级城市列表。[GeoAtlas 全国数据](https://geo.datav.aliyun.com/areas_v3/bound/100000_full.json) · [DataV 坐标说明](https://help.aliyun.com/zh/datav/datav-7-0/user-guide/map-data-format-1)

```sh
.venv/bin/python scripts/build_map_places.py
```

也可用 `--source-dir` 指定保存上述 GeoAtlas 文件的目录，离线重建索引。
